# 布局/UI 结构推断指南（按需加载）

从 ocr.py --json 的 box 坐标推断页面结构：

## 1. 层级（字号）
- `font_size` 排序，最大的 1-2 个文本 = 标题/主 CTA
- 相同 font_size 聚簇 = 同一层级（按钮组、正文段、导航项）
- 聚类容差 6px（中文字号比英文大 1-2px 是正常排版）

## 2. 列与行（对齐）
- 多个文本 x1 相同 → 同一列（侧边导航、表单标签列）
- 多个文本 y 中心相同 → 同一行（工具栏、表头、卡片行）
- 居中对齐：文本中心 x 相同（如弹窗标题）

## 3. UI 结构描述模板
```
页面: <仅基于文字与坐标，不虚构视觉>
- 顶部栏: [y 最小区域的文本们]
- 主内容: 标题「x」+ 正文「y」+ 按钮「z」
- 侧边/底部导航: [按坐标分组的文本]
```
只描述 位置/层级/文字内容；**不要**声称颜色、图标、图片内容（OCR 拿不到）。

## 4. 多栏重排
双栏/三栏（报纸、dashboard）：按 box.x 分栏 → 栏内按 y 排序 → 栏间按 x 排序。
单栏页面直接按输出顺序（已按阅读顺序排序）。

## 5. 结合 analyze.py 的审查
- 字号层级 + 对齐事实 → 判断层级系统是否一致
- palette 主色 → 品牌/主题一致性（role 是启发式）
